# Specialized Checklist: Insurance Protocols (Nexus, InsurAce)

## Claim verification
- [ ] Vote-based: voter incentive aligned with truth
- [ ] Oracle-based: oracle source decentralized
- [ ] Time window: enough but not too much

## Capital lockup
- [ ] Voters cannot withdraw during active vote
- [ ] Voters punished for malicious vote
- [ ] Risk model for capital exit

## Premium calculation
- [ ] Premium reflects actual risk
- [ ] No under-pricing leading to insolvency
- [ ] Premium adjustments rate-limited

## Bond-jumping
- [ ] Voters can't switch sides for arbitrage
- [ ] Vote weight = staked tokens (not just balance)

## Claim payout
- [ ] Payout cap per claim
- [ ] Payout cap per cover
- [ ] Insufficient pool handling (pro-rata?)

## Cover purchase
- [ ] Cover can't be retroactive
- [ ] Cover expires correctly
- [ ] Cover renewal handled
